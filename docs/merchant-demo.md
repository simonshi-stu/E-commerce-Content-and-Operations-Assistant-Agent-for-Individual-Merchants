# 片集 · 商品视频演示
这个入口只演示「素材 → 镜头卡 → 模拟任务 → 预览与归档」。无需账号、API key、npm install 或 FFmpeg。

## 启动
在本分支或解压后的演示包根目录，用 Node.js 18 或更高版运行：

    node scripts/mock-demo-server.js

打开终端显示的 http://127.0.0.1:4178/ 。也可以用 `npm run demo:merchant`；端口被占用时用 `node scripts/mock-demo-server.js 4180`。关闭终端或按 Ctrl+C 停止。不要运行主工作台的 `npm start` 来试这个演示。更换端口或浏览器会切换数据存储空间。

## 两分钟试一遍
1. 点击「一键加载演示素材」。在 DEMO-001 下会出现粉色眼镜图和一段动画，镜头区有上一段的合成人物 01。再点一次不会加倍。也可在输入 SKU 后选择或拖入自己的图片/视频；同一 SKU 相同内容只留一份，改名也不会重复。
2. 点击「试用『看价签拿梨』」再点「整理成镜头卡」，或输入「看价签拿梨，6 秒，跟上一段同一个人。」。检查动作、6 秒、上一段的角色、竖屏 9:16 和禁广告词，然后可逐项修改。尚无上一段时会提示补参考，不会凭空编造人物。
3. 把时长改成 8 秒，在「偏好优先级与保存」里选择当前 SKU 后保存。输入不含时长的指令「展示镜腿，跟上一段同一个人」得到 8 秒；重试明确写 6 秒的指令就得到 6 秒。优先级从低到高：系统默认 → 全局 → 本演示项目 → SKU → 本次。默认只保存你主动选的时长、比例和广告词开关。
4. 点「提交模拟任务」并刷新同一地址。最新任务按本地时钟依次显示排队、处理、完成。约 5 秒后可播放样片，或「下载归档 JSON」。样片固定为两秒几何眼镜动画，不会随动作、角色、比例或时长重新生成。费用始终是 0 元。
5. 点「清除本页演示记录」可清除这个浏览器里此演示的偏好、镜头、任务及导入副本，不改动原始文件。

## 这个版本的边界
- 服务端仅监听回环地址，只读提供指定静态文件；没有上传、生成、代理、成本查询或凭据入口。样例图片、人物和动画均为本演示原创合成图形，无私人媒体。
- 浏览器 IndexedDB 保存选择导入的素材副本，localStorage 保存镜头和最新任务；同一浏览器配置与端口可恢复，不是账号云同步。请不要在共享浏览器资料中导入敏感内容。配额/隐私模式阻止保存时界面会提示，临时素材不能跨刷新恢复。
- 支持 JPEG/PNG/WebP、MP4/WebM；每个文件最多 25 MB，最多 60 份合计 48 MB。正面、侧面、人物、细节是按文件名打的暂定标签，并非视觉识别。相同内容按 SKU 的 SHA-256 去重。仅一个演示项目、一个最近任务；“沿用”是参考标记，不进行人脸识别或实际人物一致性生成。
- 镜头拆解为规则解析，对未识别表达需手动校正；任务恢复并非查询真实供应商。任务归档采用字段允许名单：不含 SKU、角色、动作、提示词、账号、任务标识、文件名、源媒体或链接。浏览器显示的镜头卡不等于可分享的归档。
- 本次仅是现有素材库 PR 上的独立演示，未替换其服务，不部署、不合并。

## 复查
    node --test test/merchant-demo-core.test.js test/merchant-demo-server.test.js test/merchant-demo-ui.test.js

在另已配好 Playwright 和 Chromium 的环境，先启动演示再执行：

    node scripts/smoke-merchant-demo.cjs

可用环境变量 CHROME_PATH 指定现有 Chromium。该脚本使用合成输入，在孤立浏览器上下文中检查导入、重复、刷新、优先级、播放、脱敏归档、窄屏以及零站外 HTTP 请求。演示本身不需要 Playwright。

云端验收分三层：纯规则测试、真实回环 HTTP/MP4 测试、运行页面脚本的 DOM/IndexedDB 宿主仿真。第三层不代替真实浏览器的原生播放、拖放、存储或窄屏布局验收；本次云端 Chromium 启动被运行环境拒绝，以上 Playwright 脚本留作复跑。
