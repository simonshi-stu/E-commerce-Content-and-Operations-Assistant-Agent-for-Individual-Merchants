# Hypit video development and upstream declaration

This project declares its use of the Hypit upstream GitHub repository:

- Repository: <https://github.com/hypit-ai/hypit>
- Local checkout used for validation: `E:\Projects\hypit-runtime`
- Isolated local proof project: `E:\Projects\ag68-hypit-demo`

The main application does not vendor Hypit source. Its video workbench produces a review-first
handoff package and keeps generation, upload, payment, and publication behind separate operator
authorization. The isolated proof project runs a deterministic Route B composition against local
media and HTML endpoints. It is not evidence that Route A product replacement, transcription,
semantic analysis, a hosted model account, or publishing is available.

The upstream repository's own license, notices, version, and service terms remain authoritative for
the Hypit checkout. This declaration is attribution and usage documentation, not a relicensing
statement for upstream code.

## Future video development path

The project will use the following governed workflow for future reference-video production:

1. Save the reference video, source URL, observation time, rights state, and local asset path.
2. Use Hypit media tools for probe, boundary candidates, frames, tiles, and cuts.
3. When a speech service is authorized, run WhisperX transcription with word-level timing.
4. Have the semantic decomposition Agent read the complete reference, transcript, and frame evidence;
   record the hook, argument, shot structure, performance, product demonstration, captions, graphics,
   sound, pacing, transferable structure, and non-transferable rights-sensitive material.
5. Create the new Script, Brief/Treatment, SVML, SVS, and SVRUN from verified product facts and local
   authorized assets rather than copying the reference person's identity, voice, music, footage, or
   unsupported claims.
6. After Provider, credential, budget, and upload authorization are confirmed, use the selected
   Seedance route with local product assets, run `plan` and pricing checks, execute the Build, and
   perform visual QA before any release or publication.
