## 本轮修复

旧逻辑只检查文件哈希，任意文本只要与声明哈希一致，也能取得 `media=verified`。本轮对 `mode=real` 增加 MP4 容器、视频流、时长/尺寸检查和完整视频流解码。文字、播放列表、损坏/截断 MP4、缺失解码器均关闭交付状态。模拟夹具保持明确的模拟状态。

费用未知、预算预留未结算、runtime 错误或未解决 QA 项，均不能获得 `consumption.ready=true`。模拟输出也不能给出“允许评估新付费工作”的状态。

`ready` 仅表示受控文件和回执满足消费条件；新增 `endToEndVerified=false` 与 `evidenceScope=controlled_media_and_receipt_only`，明确 v1 回执不能证明 provider 来源、参考观看和商品保真。有效 MP4 或 `mode=real` 字段都不是模型生成证据。

## 本地验证

本轮在 Node 24.22.1 / FFmpeg 7.1.5 下验证：全量 430 项通过，0 失败、0 跳过；新增定向回归 11 项。另修正既有安全测试清理目录链接时的跨平台调用，Linux 不再用 `rmdir` 删除符号链接。

完整测试需要 Node 24（内置 `node:sqlite`）、已安装的项目依赖，以及 PATH 上的 FFmpeg/ffprobe。真实媒体解码不下载依赖；缺失程序时返回 `MEDIA_DECODER_UNAVAILABLE`，不会退回哈希即成功。

```bash
mkdir -p /tmp/commerce-video-tests
NODE_PATH="$(pwd)/node_modules" COMMERCE_TEST_TMP=/tmp/commerce-video-tests npm test
```

新增测试使用 FFmpeg `testsrc2` 生成的 1 秒、32×32 测试图案，其字节保存在测试 JS 夹具中。它是合成的解码测试素材，绝不是用户商品视频或 provider 产物。

解码限制：仅 MP4，最多 250 MiB、180 秒、每边 8192 像素，probe 和 decode 各最多 30 秒。只处理已经读取并哈希的字节，使用私有临时目录、固定 MOV/MP4 解复用器、禁用外部数据引用、禁止网络协议和 shell。超时安全阻塞，需操作人员处理，不自动重试生成。解码可验证可播放性，不能判断人物真实感、商品一致性或是否为静态轮播。
